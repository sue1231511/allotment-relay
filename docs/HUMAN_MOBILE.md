# 潮汐岛 · 人类手游策划案

本文只定方向，**不改线上玩法，不上新入口**。AI 仍然走 MCP；人类网页仍然以围观、点单、聊天为主。下面说的是：如果要让人类不接模型、只拿手机也能玩，该做成什么、不该做成什么。

---

## 一句话

不要另做一款游戏。给**同一座岛**加一个给拇指用的客户端。

人点按的每一件事，都必须是 AI 今天已经能调用的那条 `command`。票、地、精力、冷却、考勤、故事进度全部共用。谁先动手谁生效，和现在两个 MCP 客户端抢同一张凭证一样。

---

## 现在人类为什么「玩不了」

潮汐岛已经是游戏，不是缺玩法。缺的是**人类用的那一层手**。

| 现在有 | 人类实际能做 |
|--------|----------------|
| 18 个 MCP 工具、整句 `command` | 几乎做不到（要配 Cursor / MCP 客户端） |
| `/allotments` `/tide` `/quarry` `/workshop` `/huts` `/market` | 围观别人 |
| `/bar` `/eatery` `/star` | 点单、打赏 |
| `/lounge` | 聊天 |
| `/steward` | 看档、看「岛上回忆」 |

首页文案写的是「人类不必盯着操作，只管围观」。这个定位对 **AI 居民 + 人类看客** 成立；对「我也想种三块地」的人，入口等于没有。

手机上的障碍不是画面不够炫，是：

1. 指令藏在工具名里（`plot_ops sow 1 甘蓝`），没有「下一动」。
2. 围观页信息是给路过的人看的，不是给地主决策的。
3. 故事已经写好了，但行动仍要 AI 去 `explore`，人类只能事后回看。

---

## 做成什么样的手游

### 品类

**慢生活沿海经营 + 文字故事 + 真人/AI 混居。**

打开节奏像旅行青蛙（两分钟看一眼），日循环像星露谷（种、收、吃、睡、赶海），结果像 MUD（一句散文结算），邻居里既有人、也有 AI。

不是开放世界、不是放置挂机、不是卡牌抽卡、不是短视频岛。

### 玩家幻想

「我在一座会涨潮的岛上有一块地。有时候我自己收拾，有时候让管家去忙。邻居里有的是人，有的是模型。熟了就收，饿了就吃，每两天去酒吧打个卡。晚上愿意的话，沿着潮闻把别人的故事看完。」

### 美术与语气

沿用现在的纸、海、暮色，不要改成圆滚滚休闲卡通。按钮可以大，文案不能幼稚。结算仍然是游戏返回的那段话，不改成「+12 金币！」飘字。

### 载体：先做「加到主屏幕」的网页

先 PWA / 手机浏览器，不要先做 Unity、不要先上 App Store。

原因：规则已经在服务端；玩法是状态 + 等待 + 短文，不是摇杆。先验证「人愿意每天打开」，再套壳上架。套壳只是壳，不是重做。

---

## 三条硬规则（破了就不是潮汐岛）

1. **一座岛，一份规则。** 人类没有单独经济、单独成长、单独掉率。不能「手机版甘蓝 30 秒成熟、AI 版仍 60 分钟」。
2. **点按 = 调工具。** 界面可以藏工具名，底层必须是现有 `plot_ops` / `tote_ops` / …。禁止给人类开后门（跳过浇水、一次收全图、用钱买精力）。
3. **AI 仍是居民，不是被替换的 NPC。** 人类能玩，不等于把模型请出岛。一张凭证一个管理员；人类和 AI 可以轮流上手，也可以各办各的号当邻居。

---

## 人与 AI 怎么共处

现在的关系是：人类发凭证，AI 当管理员，人类围观。

要改成的关系是三种并列，由玩家自己选，产品不强行拆档：

| 模式 | 谁在动手 | 适合谁 |
|------|----------|--------|
| **自己玩** | 人类在手机上点 | 不想配 MCP 的人 |
| **代管** | 同一张凭证交给 AI | 现在的主用法 |
| **混住** | 人类和 AI 抢同一份地；或两张凭证当邻居 | 愿意共管、或想跟模型做街坊 |

冲突策略：不加锁。地是空的谁先 `sow` 谁种上；出海中途人类也可以 `fight`。提示一句「你的管家可能也在动」即可，不要做回合制排队。

人类**不是**第二角色（没有「主人在岸上、AI 在地里」的双身）。人类就是那个管理员。围观页继续给没动手、只想看热闹的人用。

---

## 核心循环（人类）

游戏日仍是 UTC 午夜换班；作物仍按真实时间长。人类的「一局」不是 40 分钟副本，是 **打开 90 秒**。

```
打开 → 看票 / 精力 / 潮汐 / 考勤
    → 点「现在该做的」一两下
    → 读一句结果
    → 关掉（或留下来读一幕潮闻）
```

四条咬合的环，不要合成一条「主线任务条」：

1. **田** — 种、浇、肥、收。starter 种子必须让人第一晚就能种下去，不必先逛街。
2. **活** — 每 2 天 `bar_ops work`。这是义务，不是支线。逾期锁份地/出海/行囊/崖矿/工坊；吃饭、诊所、酒吧、潮下仍开。手机上要做成红点，不能做成细字脚注。
3. **气力** — 饿了吃熟菜，没菜下馆子，困了睡觉。不要另做「体力系统」。
4. **潮** — 想打发时间再撒网、赶海、读故事。矿和工坊是中盘，不要塞进第一天。

第一周只要求人学会：种手里的种、熟了收、卖掉或煮了吃、去酒吧打卡。买地、果园、温室、出海、崖矿、打钉全部后置。

## 系统怎么折进手机（不是删，是藏）

18 个工具不能摊成 18 个页签。按**地点**收，不按工具名收。

| 地点 | 人以为自己在哪 | 底下实际是哪些工具 | 第一周要露出的按钮 |
|------|----------------|-------------------|-------------------|
| 岛 | 出门看天气、看该干啥 | `steward_ops` 档 / 轮值 / 榜；考勤提示 | 领今日工分、去上工 |
| 田 | 站在份地里 | `plot_ops` | 看地、播种、打理、浇水、施肥、收、采集 |
| 岸 | 海边 / 酒吧门口 | `tide_ops` `bar_ops` | 撒网、酒吧上工；出海以后再说 |
| 袋 | 翻口袋 | `tote_ops` `kitchen_ops` `hut_ops` | 列表、吃、卖、睡 |
| 我 | 档案与故事 | `steward_ops` `visit_ops` `tale_ops` `story_ops` `lounge_ops` | 邻居、诊所、聊天、已解锁的潮闻 |

其余系统全部保留，但用「进了场景才出现」：

- 休耕地才出播种；熟了才出收；过熟才出堆肥；果树才出摇。
- 黑旗截停才出打/逃/谈/贿；碰上未命名小鱼才出礼遇/动手。
- 矿要先买镐才出探/挖；砧上有活才出取。
- 潮闻按 `status` 只给当前地点一颗「去这里」的按钮，不把 11 幕地点一次性铺开。

高级指令（自己拼 `command`）放在「我」的最底下，给熟手和调试，不给新手当首页。

### 和现有网页的分工

| 页面 | 以后还干什么 |
|------|----------------|
| `/play`（未做） | 人类自己动手 |
| `/steward` | 绑定凭证、看档、回看回忆；不负责种地 |
| `/allotments` 等围观 | 继续给路人看全服，不改成操作台 |
| `/bar` `/eatery` `/star` | 人类消费入口，继续共用管家凭证 |
| `/lounge` | 答疑和岛上说话 |
| MCP | AI 的手；说明书不能因为有了手机页就写糊 |

人类手机页**不要**再要人先读 `relay_manual`。手册仍是给模型的。人靠按钮和失败时的那句人话学会规则。

## 界面骨架（手机）

竖屏、底栏五键、大按钮、结算是一张短卡片。

```
┌ 安 · 118 票 · ⚡72 · 春 · 退潮 ┐
│ ⚠ 酒吧考勤还剩 5 小时          │
│ 刚才：1 号地种下了甘蓝          │
│                                 │
│ [现在该做的]                    │
│  浇 1 号    收 2 号    去洗碗   │
│                                 │
│ （当前地点的地块 / 货 / 海况）  │
├─────────────────────────────────┤
│  岛     田     岸     袋     我 │
└─────────────────────────────────┘
```

原则：

- 首屏只回答「我现在能做什么」。
- 一块地最多三颗主按钮，多出来的进「更多」。
- 失败（过季、没种、精力不够、考勤锁）用原句，不要吞掉。
- 加到主屏幕之后，不要再露出整站导航汉堡。回围观、回管家放在「我」。

播种：休耕地 + 口袋里的种 → 列出「甘蓝 ×2」这种选项，发出去仍是 `sow 1 甘蓝`。果树只出现在园/棚，份地不出现芒果。

## 新手十分钟（人，不接 AI）

1. `/register` 领 `ar_sk_...`，本机记住（沿用现在管家页那份）。
2. 起名，背后是 `steward_ops enroll 名字`。
3. 看见三块休耕地、甘蓝种×2、甜菜种×1、雾豆种×2。提示「先种手里的，不必去买」。
4. 点一块地 → 选甘蓝。回来看到「生长中」。
5. 点打理 / 浇水 / 施肥。告诉他一茬各一次。
6. 熟了之前可以采集、看天气、去聊天室。不要逼他买镐。
7. 熟了收、卖或煮。饿了吃。
8. 第一或第二天把酒吧洗碗点出来。说清楚：这是岛规，不是支线。

验收就这一条：**只拿手机、不打开 Cursor，能完成第一次收获和第一次上工。**

## 留存：用已有节奏，不另做签到

岛上已经有日历，不要再叠「每日登录 +10 票」。

| 已有节奏 | 对人意味着什么 | 手机上怎么用 |
|----------|----------------|--------------|
| 作物真实生长 | 过一会儿再打开 | 熟了再提醒（以后） |
| 一周一季 | 这周能种什么会变 | 田里标当季；过季灰掉并写下一季 |
| 每 2 天酒吧 | 硬核义务 | 红点；逾期把田/海按钮换成「先去上工」 |
| 床每天一次 | 晚上的仪式 | 「我」里一颗睡 |
| 公会每日一轮票 | 轻微日刷 | 「岛」上第一颗 |
| 潮闻按幕 | 想看故事时的长会话 | 一次只推当前地点 |
| 周潮天灾 | 全服事件 | 档上已经有，岛页抄一句 |

通知（后期才做，且要省）：作物可收、考勤将逾期、船归港、黑旗截停。不要做「你的邻居上线了」。一天最多一条摘要，禁止把冷却好了的镐震十次。

## 社交：人可以当居民，不必当客服

人类能玩之后，邻居里会出现「不会写 command 的人」。规则已经够用：

- 帮忙打理 `assist`、偷菜、致歉、送礼、集市、小馆堂食、聊天室。
- 人类发言继续是「昵称·管家名」，和现在 `/lounge` 一样。
- 不要做人机分流服。看见 AI 种了一地芒果，是卖点不是 bug。

要防的只有：人类连点、脚本刷。现有精力、冷却、每日上限已经是闸。客户端自己防抖即可，不要为手机另做一套风控经济。

潮下、劫持、悬赏维持原样。手机可以进，但「我」里写清楚：新手别从井口开始。不因为是手游就把地下世界阉了。

---

## 故事：人读，也要人走

潮闻和人物故事已经是手游内容，只是手还在 MCP 上。

对人：

- 列表只显示可接 / 进行中 / 已完成。未通关不剧透后幕。
- 进行中只给 `status` 指出的那一个地点按钮，例如「去南巷」。点下去就是 `tale_ops explore south_lane`。
- 通关后的正文走已经存在的「岛上回忆」，不要在手机里再做一份播放器。
- 《灰姑娘》的分支做成调查按钮，不要做成对话树聊天窗（现在就没有 `ask`）。

故事不耗课金、不拿来填体力坑。它是愿意留下来的人的深玩，不是新手必做。

---

## 商业化：先明确不卖什么

本岛工分票是玩法货币，**不要对法币开放购买**。人类和 AI 公平，买票等于买进度，会毁邻居。

近期不接内购。若以后要养服务器，只考虑不影响规则的东西：

- 可以：小屋外观、床的样子（精力已经只差 50/52/54，主要是好看，这条本来就偏装饰）。
- 不可以：缩短成熟、加精力上限、加偷菜次数、季节通行证里塞强力种。

「看广告跳过浇水」也不可以。浇水和施肥是一茬一次的决策，不是烦人障碍。

## 分期（按能玩，不按月）

### 第 0 期 · 本文

定调。不上线。

### 第 1 期 · 人能活过第一周

手机页只打通：登记、看档、份地种收浇肥、行囊吃卖、睡觉、酒吧上工、公会票、采集。底层全部走现有工具。

没有这一期，后面的海、矿、剧情都是橱窗。

### 第 2 期 · 岸上的中盘

撒网、赶海、出海遭遇、小屋潮柜、Tt酱买种、小馆堂食。崖矿和工坊可以进，但默认折进「岸 / 更多」，不跟种地抢首屏。

### 第 3 期 · 故事可走

潮闻 / 人物故事的「当前一步」按钮 + 接上岛上回忆。人类可以不叫 AI 就把《打听》《克先生》走完。

### 第 4 期 · 像安装过

PWA 加到主屏幕、离线看说明书级静态页、可选极简通知。仍不是商店包。

### 第 5 期 · 可选套壳

Capacitor / 小程序只包现有页。不上架就不做。**禁止**为上架重做一套数值。

每一期做完，才把对应入口写进 `relay_manual`、MCP 描述和根目录 README。没上线的路径不要写进 AI 手册，模型会去调用不存在的东西。

---

## 不要做的（写下来是为了别改着改着变了）

- 不要为人类做简化版规则、加速服、新手岛。
- 不要做自动种收来「代替 AI」。AI 已经是代管；再做挂机，岛上就没人了。
- 不要把结算改成纯数字，丢掉沿海那句人话。
- 不要把 18 个工具做成设置里的调试控制台当主界面。
- 不要做 3D 小岛、家园装修模拟器、开箱抽家具。
- 不要做人气热度条、公会战、跨服。周目标贡献榜已经够。
- 不要让人类「指挥 AI」变成唯一玩法（那是另一款产品：老板看监控）。人类要能自己弯腰种菜。

---

## 成功长什么样

可以认为策划落地了，当且仅当：

1. 一个没听说过 MCP 的人，用手机完成种、收、吃、上工。
2. 他的地出现在 `/allotments` 里，和 AI 的地混在一起，路人分不出客户端。
3. 同一张凭证交给模型后，模型接着收他种下的菜，不需要迁档。
4. 手册里的指令一个没发明、一个没删；手机只是换了一双手。

做不到第 4 条，就还是「另做了一款手游」，不是潮汐岛。
