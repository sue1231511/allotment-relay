# 潮汐岛《玩法全景》

给不写代码的人看。这份文档只读代码和说明写成，没有改任何代码。

## 先说清楚：数字从哪来，哪些是估的

- **有出处的数字**：来自代码里的常量（每日次数、精力、工资、价格表）。下面写「代码里写的是」的，都是读源码确认的。
- **估算**：我手头没有线上数据，没有真人玩家的实际流水。「一天赚多少」都是按代码常量推的情景，不是实测。凡是估算我都写了「估」。
- **没核实的**：我读到了入口，没跑通或没读全的，写了「没核实」。
- 票 = 工分票。精力 = 做大部分事要花的体力，上限 100，不动时每 20 分钟回 2 点，睡觉回 50 左右，吃熟菜回 22 起。
- 「系统造票」= 玩家做了某件事，系统凭空给票，没有别人少票。「玩家之间」= 票从一个人转到另一个人，总量不变。「销票」= 票交出去就没了（或进了公共基金）。

## 一、一页纸看懂：三条产出线、一道强制打卡、一堆花钱的地方

1. **种地线（零精力）**：买种 → 种 → 浇/打理 → 收 → 卖给系统（vend）或做成菜。不花精力，只受「有几块地、多久回来看一次」限制。
2. **精力线**：撒网/赶海/挖矿/出海/酒吧上工/演出，都是花精力换票或换材料。
3. **做饭线**：把种出来、钓上来的东西拼成菜，卖给系统或吃掉回精力。
4. **强制打卡**：酒吧上工。每 2 天不上一次工，份地、出海、行囊、矿、工坊都会被锁。这是岛上唯一的「强制打卡」。
5. **花钱的地方**：买地、小屋、船、婚礼、衣服、诊所、岸税、岸维、赌场。票最后基本花在这里或进了潮汐基金。

## 四、谁和谁有联动，谁是孤岛

### 联动最紧（物品在多个玩法间流转）

- **种地 → 做饭 → 吃 → 精力 → 其余所有要精力的玩法**。这是最粗的一条主动脉。
- **海 → 鱼 → 做饭 / 渔排 / 小馆 / 陈列 / 联盟周目标**。
- **崖 → 矿 → 工坊 → 船部件、网补丁、家具、信物**；**崖盐 → 潮下炼制 → 厨房黑盐/腌卤**（唯一一座横跨崖、井、厨房的桥）。
- **畜栏 → 粪/奶/蛋/毛 → 堆肥、奶酪、毯子、菜**；堆肥 → 地。
- **Tt 杂货 ↔ 全部**：种子、工具、嫁妆都从这儿来，好感折扣影响买价和退货价。
- **婚礼 ↔ 小屋、Tt、衣泊坊、海边、小馆/酒吧、工坊**：想办婚礼要用到九个以上的系统，是联动最多的单个目标。
- **岸税/岸维/基金 ↔ 票多的人**：唯一一套自动把票从富的转到穷的的机制。

### 孤岛（没人连着，或连得很弱）

- **聊天室 / 红包 / 许愿墙 / 听潮亭**：纯社交，只有红包搬票。
- **日常心意（heart_ops）**：只扣票、不进行囊，和别处没有物品往来。
- **潮闻 / 人物故事**：一次性，奖励是票和永久纪念品，不流入任何别的玩法。
- **漂流瓶、lore scan、岛缘、成就、收集簿、周报**：只有记录，没有产出。
- **共同出游**：只留回忆，不给票也不给资源。
- **韶年卜卦、阿槐送别、守夜灯**：小额花钱买氛围，几乎不影响别的系统（卜卦有点小加成，没核实全部）。
- **世界 Boss**：和别处只通过「神话章鱼肉」一件材料连着。
- **赌场、深坑**：自成一套，票进票出，不产出任何别的东西。
- **吊床、梳妆台**（代码里有，见第六节）：几乎不影响任何系统。

## 五、收益偏高 / 偏低

按「每点精力能换多少票」排：

| 玩法 | 估算 | 判断 |
|---|---|---|
| **种地** | 零精力。羽衣甘蓝一茬 5 件×16 = 约 80 票/块，种子 7 票，生长 60 分钟。买地的钱和岸维都远低于单茬收入（超过 3 块的地每天 10~28 票/块，第 4 块地 80 票，一茬就回本）。土壤肥力最多让生长慢 14%，没有产量上限，卖价也不随卖量下跌（鱼会，作物不会）。 | **岛上最强的赚钱线，上限只取决于有几块地、多久回来看一次**。买地没有数量上限，只有递增的价格、开垦等待时间和按块算的岸维，这几项相对一茬 80 票都很小。 |
| **灶台自由组合** | 每天 24 次，估均价约 108，满做约 2.6k 票/日（按「每次都做满」算的上限）。 | **比种地一天约 500 高出 5 倍**，是否有意设计，需要你定。已记入 `docs/economy-todo.md`。 |
| **酒吧牛郎夜班** | 工资 80 + 提成均值约 25 + 小费均值约 6 ≈ 111/次，10 精力 → **约 11 票/精力**，每天 4 次约 440 票，要求服务熟练度 ≥8。 | 精力线里最高。 |
| **酒吧调酒师夜班** | 70 + 6 ≈ 76/次 → 约 7.6 票/精力。 | 偏高。 |

偏低的玩法大多是「故意做得费」（崖矿、赶海）或「本来就不指望赚钱」（心意、聊天、婚礼、衣服）。
偏高的两条最值得你看：**种地没有规模上限**，**灶台自由组合没有收益上限**。

## 六、说明和代码对不上的地方

### 说明里写了，代码里没有（或做不到）

我把 README 每个工具表里反引号写的命令，逐条真的打进游戏跑了一遍（用一个干净的新号）。**没有发现「README 写了一条命令，游戏回答不认识」的情况。** 看起来像不认识的几条（`buy skiff`、`install`、`调理 中`、`结束` 等）是 README 把「`voyage buy skiff`」「`clinic 调理 中`」写成了简写的行，实际命令存在。这一步只验证了「命令存在」，没有验证每条命令的结果和说明写的一致。

另有两处**文字描述对不上**：

1. **assist 的 +2 票**：README 写「协作 ≥60 时对方额外 +2 票」，容易被读成给被帮的人；代码里这笔票给的是**出手帮忙的人**。
2. **assist 本身的 +8 票**：README 没写。代码里每次 assist 无条件给帮忙的人 8 票（系统造票）。

### 代码里有，说明里没写（或写在 MCP 描述里、README 表里没有）

- **README 工具表缺**，但 MCP 描述里有：泡澡、读书、肥力/轮作、虫害处置、留种、地陷、捞瓶/投瓶、灶险、棚险、卦险、小屋改名（label）。
- **说明里都没写**：麻绳吊床（40 票，没有床时睡一觉回 35 精力）、贝壳梳妆台（44 票，睡醒/泡澡后档信 +1）两件家具。README、人类手册、relay_manual 都搜不到；玩家只有翻小屋目录（hut_ops catalog）才会发现。
- **人类手册里完全没有**（搜不到）：世界 Boss（讨伐）、共耕、劫持/K 室、潮闻之外的 `灾选/待选`（手册里只有「灾档」）、工坊陈列柜（捐 砧上全套）。潮下玩法人类手册只用了一两句话带过，而手机地图上钱庄、赌场、后室铺、恩怨墙、医务间都能点——**人类玩家在手册里找不到这些玩法的说明**。

## 七、一个普通玩家的一天（情景，不是实测）

**假设**：一个第二周的真人玩家，手机上玩，一天分三四次上线，每次 10~20 分钟。有 6 块份地、一栋 Lv2 小屋、细渔网、T1 镐。

| 时间 | 做什么 | 花的精力 | 得到的 |
|---|---|---|---|
| 早上 | 收昨晚种的菜，重种，tend、浇水；领 guild | 0 | 约 18 + 6 块×约 80 = 约 500 票的货（要 vend 才变成票） |
| 早上 | 煮 2~3 次自由组合，吃一道熟菜 | 回 22 | 菜约 100 票/份（卖给系统） |
| 中午 | 赶海 2 次 | 16 | 约 32 票的杂货 |
| 中午 | 撒网 5 次 | 35 | 约 5 条鱼，约 125 票（卖或做菜） |
| 傍晚 | 睡一觉 | 回 50 | — |
| 晚上（暮/夜开门） | 酒吧上工 2~4 次 | 20~40 | 约 70~170 票 |
| 晚上 | 点杯酒、逛集市、看聊天室、玩一段故事 | 5~10 | 故事每步 30 票 |

**时间主要花在哪**：

1. **等和跑腿，不是动手**。作物要等 60 分钟以上，赶海 30 分钟一次，崖矿全坑 36 分钟一次。一次上线能做的事不多，所以大部分时间是「回来看一眼」。
2. **每 2 天必须上一次酒吧工**，不然份地、出海、行囊都锁。这是最容易让新人撞墙的一条。
3. **精力是实际天花板，但种地不花精力**。精力上限 100，一天可用的大约是被动回的 144 点（每 20 分钟 +2）加睡觉 50 点，再加吃饭，合计 200 点上下，而不是 100。想多赚，多种地比多撒网划算。
4. **花票的地方**：前两周主要花在买地、买小屋、买网、买镐、买船这几笔一次性大头上；之后每天固定扣的是岸维、岸税，富人的税更重。到有钱了，唯一能大量花票的是婚礼（约四万）和衣服/嫁妆/吃席。

**一个新手容易误会的地方**：

- 钓上来的鱼不直接是票，要 `tote_ops vend` 或做成菜。
- 作物同理，不卖掉就一直在行囊里。
- Tt 退货只给买价的九成，不是白拿。
- 订婚戒、潮誓戒这类信物现在只能送人或挂集市，不能卖给店。

## 八、这份文档的边界

- 没有线上数据，所有「一天赚多少」都是情景估算。
- 世界 Boss 的击杀窗口、assist 谁得票，是读代码得出的，没有跑线上验证。
- 孤岛判断是我读代码、README、手册后的判断，没有做用户行为统计；一个玩法是不是「没人玩」，要看线上数据。
- 韶年、阿槐、何敬山、守灯人的具体小加成，我没有逐条读完，只确认它们是小额。
- 第六节「人类手册里搜不到」只做了关键词检索，不排除手册用了别的叫法写过。
