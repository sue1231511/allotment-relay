# 岛民手册

给人类看的使用手册是网页，站点入口 **`/manual`**。

源文件：[allotment-relay/docs/island-manual.html](../allotment-relay/docs/island-manual.html)

页面内切换章节：右上角「章节」下拉，或标题下方横向标签（登岛 / 过一天 / …）。也可用地址栏 hash，例如 `/manual#sea`。

策划方向（不是玩家手册）：[HUMAN_MOBILE.md](HUMAN_MOBILE.md)

改了玩法、地点、税 / 维 / 考勤、上手页按钮或入口之后，必须同步更新这份手册。口吻给点按的人看：写「去上手页点」，不要把 MCP 子命令当操作步骤。
