# 潮汐岛完整玩法扩展方案

## 一、总体方向

后续不要只继续堆独立玩法。

重点改成：

**生产 → 消耗 → 损耗 → 维修 → 加工 → 交易 → 随机事件 → 再生产**

每个系统都要和其他系统产生关系。

核心原则：

1. 不能只有收益，没有损耗。
2. 不能只有成功，没有失败。
3. 坏事件不能只是扣票，要有选择。
4. 新物品尽量有至少两个用途。
5. 稀有物尽量接入履历。
6. 岸上和井下互相影响。
7. 小屋不只是展示，是重要消费中心。
8. 菜、鱼、牲畜、作物本身要大量扩充。
9. 高级物品不一定纯强，要有代价。
10. 玩家可以做错误选择，不强行替玩家兜底。

---

# 二、全局损耗系统

## 1. 耐久

增加统一耐久框架。

适用：

- 船
- 船帆
- 船舵
- 船灯
- 鱼舱
- 钓竿
- 鱼线
- 渔网
- 鱼钩
- 镐
- 农具
- 温室
- 畜栏
- 灶台
- 冰箱
- 家具
- 小屋屋顶
- 门窗

耐久来源：

正常使用、天气、事故、腐蚀、超负荷使用、长期不维护。

耐久低不直接锁死。

改成：

- 效率下降
- 故障概率提升
- 事故概率提升
- 品质下降
- 维修价格提高

玩家可以继续硬用。

# 三、随机坏事件

坏事件统一分四档。

## 轻微

常见：

- 鸟啄菜
- 鱼脱钩
- 家具发潮
- 灶台不好点火
- 动物闹脾气

## 麻烦

偶尔：

- 冰箱坏
- 羊逃跑
- 病虫害
- 船帆撕裂
- 温室漏风

## 危险

少见：

- 船底进水
- 牲畜传染病
- 矿坑塌方
- 房屋漏雨严重
- 鱼舱坏掉

## 灾难

极少：

- 强风暴重创船只
- 大规模疫病
- 地下潮压异常
- 岸上地陷
- 大面积作物毁坏

---

# 四、坏事件不能只扣钱

每个坏事件尽量提供不同选择。

例如：

## 船帆撕裂

修补：
消耗漂绳和布。

返航：
损失本次航程。

继续航行：
不立即花钱，但事故概率提高。

## 甘蓝盐斑

拔掉：
立刻损失这一株。

施药：
花钱，有概率救活。

不管：
可能自己恢复，也可能传染邻地。

## 山羊生病

兽医：
贵，成功率高。

自己处理：
便宜，存在误诊。

拖着：
可能恢复，也可能恶化。

---

# 五、坏事也能带来机会

部分坏事件增加低概率特殊结果。

比如：

- 船搁浅 → 发现漂流箱
- 塌方 → 露出稀有矿层
- 暴雨 → 冲出特殊贝壳
- 动物逃跑 → 找到隐藏地点
- 断线 → 未来可能重新钓回旧鱼钩
- 病株烧毁 → 得到特殊灰肥
- 风暴毁船 → 捞到别人的残骸

这样坏事不是单纯惩罚。

# 六、小屋系统

## 2. 房屋耐久

天气会损耗房屋。

低耐久可能：

- 漏雨
- 家具受潮
- 冰箱效率下降
- 床恢复下降
- 熟食腐败更快
- 墙面发霉
- 门窗损坏

维修材料：

- 岸木
- 铜钉
- 漂绳
- 工分票

形成：

崖矿 → 铜矿 → 工坊 → 铜钉 → 修屋

海边 → 漂绳 → 修屋

## 3. 家具不再纯升级

例如：

### 软藤床

优点：
恢复高。

缺点：
潮湿天气损耗快。

### 云纹床

优点：
雾智恢复高。

缺点：
维修贵。

### 潮眠床

优点：
综合恢复强。

缺点：
偶尔做怪梦。

## 4. 家居套装

### 渔夫之家

鱼拓、盐灯、粗网装饰、木桌。

好处：
钓鱼耗材损耗降低。

坏处：
部分 NPC 来访满意下降。

### 矿工之家

矿灯、铁架、夜光髓摆件。

好处：
挖矿恢复快。

坏处：
睡眠质量下降。

### 花房之家

干花、花茶架、藤椅、香炉。

好处：
NPC 来访率提升。

坏处：
火灾风险略升。

## 5. 家庭杂务

随机：

- 冰箱结霜
- 门轴坏
- 屋顶渗水
- 鼠患
- 木材虫蛀
- 灶台堵塞
- 家具发霉
- 灯具坏

处理方式：

- 自己修
- 找 NPC
- 暂时不管

## 6. 家庭持续消费

高级房屋可增加：

- 冷藏费
- 灯油
- 灶台燃料
- 清洁
- 防潮
- 家具维护
- 动物卫生

不缴不封房。

只是设施性能下降。

# 十、土壤系统

每块土地有肥力。

连续种同类作物：

肥力下降。

轮作：

肥力恢复。

例如：

甘蓝 → 甘蓝 → 甘蓝

越来越差。

甘蓝 → 雾豆 → 甜菜

恢复更好。

还能增加：

- 盐碱
- 湿度
- 土壤病害
- 有机质

不用一次全做，可以逐步上。

# 六十、最终应该形成的玩法关系

种地  
→ 土壤下降  
→ 轮作  
→ 遇到虫害  
→ 鸡帮忙吃虫  
→ 鸡可能刨坏菜  
→ 收到不同品质蔬菜  
→ 好菜进小馆  
→ 差菜喂牲畜  
→ 剩余堆肥  
→ 腌制加工  
→ 市场出售。

捕鱼  
→ 消耗鱼线鱼钩  
→ 大鱼可能断线  
→ 收到不同品质鱼  
→ 好鱼做高级菜  
→ 大鱼做鱼拓  
→ 普通鱼腌制  
→ 鱼进冰箱  
→ 冰箱可能损坏  
→ 为防腐败赶紧加工。

牲畜  
→ 吃饲料  
→ 产生蛋奶毛粪  
→ 粪进堆肥  
→ 堆肥回农田  
→ 奶蛋进料理  
→ 羊毛进工坊  
→ 动物会生病、逃跑、繁殖。

出海  
→ 船损耗  
→ 修船需要岸木、铜钉、漂绳  
→ 铜来自崖矿  
→ 岸木来自岸上  
→ 漂绳来自海边  
→ 船升级进入深海  
→ 深海获得特殊鱼和材料。

井下  
→ 获得特殊材料  
→ 岸上制造高级物品  
→ 产生井蚀  
→ 影响小屋、动物、菜地  
→ 潮生会工程又能反过来改善地下环境。

最终不要做成几十个互不相干的按钮。

要让玩家发现：

**我只是想钓条鱼，结果鱼线断了。为了换线去集市，顺手发现冰箱坏了。冰箱坏了鱼得赶紧腌，于是发现家里没盐，只能去收盐田。收盐时又赶上风暴，船帆又裂了。**

这才叫潮汐岛。
