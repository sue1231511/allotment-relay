## 默语花房

默语花房：手机地图总览点「集市」，像广场一样选地名「集市 / 花店」。选花店先进店景，点一下见柜台左侧默默，再点对话出选项，回应留在原框。保留玩家集市交易，不加总览花店图标。

AI 使用 `visit_ops`：`默默`（空子命令打招呼）、`默默 scan`（只读花单，不领奖）、`默默 买花 玫瑰`。每日三种花、玫瑰常售，48～88票，种地/赶海域最多减8票；鲜花可送可卖，不是花种。每日首次招呼送当季花（档信+1）或试饮（精力+3/雾智+1），`默默 花语` 首次免费、之后5票。UTC午夜刷新（北京时间早8点）。

`默默 花茶 玫瑰花茶` 买现煮38票（精力+10/雾智+2），桂花姜茶48票（+14/+2），菊花香茅茶28票（+8/+1），均受上限限制。茶名加「包」买包、少8票，`默默 花茶 冲泡 玫瑰花茶包` 耗包、不再收费。`默默 记名` 打过招呼后每日记一次、7天得称呼「花房熟客」，不发票。`默默 干花 玫瑰` 耗鲜花一枝+28票挂小屋空软装槽，无房/满槽不扣不耗、不覆盖家具。纯装饰，可去小屋查看/变卖；替换回行囊后 `hut_ops install soft_1 flower_rose` 重挂。`默默 告别` 不消费，`默默 help` 看完整说明。不是栗栗换货、玩家集市或约会导演，无赊账，无新 `flower_ops`。

站长配置剧情模型（OpenAI兼容 Chat Completions 接口，玩家不用填设置）：

```text
DATE_DIRECTOR_URL=https://你的接口域名/v1
DATE_DIRECTOR_API_KEY=你的密钥
DATE_DIRECTOR_MODEL=你的模型名
DATE_DIRECTOR_MAX_TOKENS=4096
DATE_DIRECTOR_TIMEOUT_SECONDS=120
```

`DATE_DIRECTOR_MAX_TOKENS` 可省略，默认4096，范围1024～16384；输出截断、空正文或格式不符会显示明确提示。

继续/选择/自定义由服务端后台生成。快模型直接返回旁白；慢模型先回「已受理」，AI 应隔几秒用 `出游 查看` 读结果，不要重复推进。MCP 返回、断线或取消请求不会取消已受理的本幕；查看不调用模型，也不自动进入下一幕。手游等旁白自动显示即可；`出游 退出` 才停止这一程。可选 `DATE_DIRECTOR_TIMEOUT_SECONDS` 默认120秒、范围15～300，控制导演总等待时间；超时或正常停服保留原幕并显示失败原因，不自动重试。原幕重试不另付预订费；强制终止进程可能只留下过期占用提示。

也接受完整 `/chat/completions` 地址。密钥只在服务端请求中使用，不返回手游或 MCP。模型调用的实际 API 费用由站长账户承担，与游戏工分票不同。未配置时不接受新约会、不扣预订费。模型需输出 JSON，超时或格式错误保留原幕，可重试原指令或退出。付费选项服务端定价：双人餐188 / 特别晚餐298 / 甜点68 / 留影88 / 夜航268 / 花束128，转场按目的地预订费。

## 推送前 / 改完后（必做）

细则写在根目录 README 的对应章节。这里只强调两条，不许跳过：

1. **推送之前**必须 `git fetch origin` 并 `git merge origin/main`，确认云端没有你本地没有的提交，再推功能分支。禁止不拉云端就推、禁止 force 推 `main`、禁止用整文件覆盖刚合进来的改动。
2. **每次改玩法之后**必须同步更新：`server/mcp_app.py` 的工具描述、`game.py` 的 `relay_manual`、各工具 `help`，以及给人类看的 `server/templates/partials/island-manual-content.html` + `server/static/island-manual.css`（站点 `/manual`）。每个工具都要写清用途、空 command 默认、可复制的例子。人类手册写「去上手页点」，不要把 MCP 子命令当操作步骤。没更新说明，任务不算完。
