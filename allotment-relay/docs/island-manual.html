先上岛。
别先读百科。

潮汐岛不是一张任务清单。新人第一天只需要知道怎么种、怎么吃、怎么睡、怎么别因为忘记上工把自己锁在门外。

01
播种

点一块休耕地，把手里的种子种下去。不必先去商店。起步有甘蓝种×2、甜菜种×1、雾豆种×2、堆肥×1。

02
打理

一茬打理、浇水、施肥各一次。然后让它自己长。熟了再收。急不来。

03
吃和睡

行囊能吃，小馆也能吃。小屋的床每天能睡一次。水果只能垫肚子，别当饭。

04
酒吧考勤

每 2 天去滨海酒吧上一次工。这个不是支线，是岛规。洗碗就能上。

DAILY RHYTHM

岛上的一天

不是日程表。只是你最常碰到的状态。
TIDAL DAY
BODY精力

行动会消耗。吃熟菜、下馆子、回小屋睡都能恢复。熟菜通常从 22 起，睡觉 50 上下，每天一次。

FOOD饱食

水果能垫肚子，只回 4 精力；连吃 5 口会营养不良。蔬菜不能生吃。只有生肉可能感染。

SEA潮汐与天气

赶海、盐田、矿、打捞会受影响。上手页 Today 卡写当前海况。

SEASON季节

一周一季：现实 7 天换一季，春夏秋冬循环。买种和露天/果园播种须当季；已种下的继续长。温室不受季节。

02 DAYS
每 2 天必须去滨海酒吧上一次工

逾期会锁份地、出海、行囊、盐风崖、岸工坊。诊所、吃饭、酒吧、潮下仍可用。洗碗就能打卡。不是吓你，是真的。

逾期了 → 先去上工
DAILY
扩了产业，岸维每天划

起步 3 块菜地、3 个树位、棚屋 Lv1、第一口盐田、第一个矿坑免征。多出来的地/棚/馆/船，日单价 2 起。不要拿「每周 10 票」当日付，那是 7 倍。

欠了 → 潮生会
两种「一天」别混

睡觉、公会工分、偷菜次数、酒吧日报，跟游戏日换班走。岸税、岸维、潮汐基金补贴，跟东八区日历走：税周一、维修每天、补贴周二四六。

Today 卡红条

上手页会把酒吧考勤、欠岸税、欠岸维写在同一条红带子上。潮生会卡片欠费时也会亮。先把红的处理掉，再去扩地。

CADASTRAL SHEET

土地与家

露天受季节影响
温室不受季节影响

份地

种普通作物。成熟后收、卖、做饭。新人最先学这个。份地不种果树。起步 3 块，再买无上限。

PLOT

果园

只种果树。果树按种苗有收茬上限，收满枯死。起步 3 个树位，价表同买地。

ORCH

温室

菜和树都能种，不受季节。第 1 座 180 票马上能用，之后更贵。偷不到。

SHED

小屋

睡觉、装家具、养畜栏、养吉祥物。棚屋要自己搭。可升到 Lv4 临海邸。

HUT

潮柜 / 冰箱

潮柜放生鲜，冰箱放熟菜。粪便进堆肥桶，不是柜子。行囊每格基础 24 份，可扩栈。

STORE
种不了时先查

过季没有 · 没种子 · 地不是休耕 · 酒吧考勤逾期。果树要去果园或温室，别硬往普通份地里塞。甘蓝 / 甜菜 / 雾豆 / 浅海藻全年可种。种袋空了，份地栏可以直接买种。

扩地、买园、买棚

上手页看价钱和开垦时间，确认才扣票。欠岸税或岸维时，确认按钮会变成「去潮生会」。先把税和维修交了。

偷菜与邻居

最多掐走 30%，永远留一把；温室摘不到。被摘了可以致歉。稻草人、监控、守夜狗会让对方更难得手。

浇水免费，施肥耗堆肥或粪便，一茬各一次。过熟可以堆肥清掉。砍树会掉岸木。吉祥物喂养花 4 票，不是岸维。

COASTAL CROSS-SECTION

靠海吃饭

岸上 → 潮间带 → 近海 → 深处
越往下，成本和麻烦越多
岸边

撒网要渔网，坐钓要钓竿和饵。有些东西只能钓到，网不到。竹钓竿 Tt酱有卖。

NET / CAST
潮间带

赶海先看潮位。涨潮时不能翻沙、不能探，但还能扫一眼海滩。翻沙要铲子，不是挖矿。

BEACH
外海

近岸 / 外海 / 深漂，要船。黑旗截停时会出现打、逃、谈、买路。船也交岸维。

VOYAGE
崖与工坊

盐风崖：买镐、探脉、挖、洗。岸工坊：打钉、补网、晒盐、风暴打捞。第一口盐田、第一个矿坑免岸维。

QUARRY / CRAFT
三件别叫错的事

赶海翻沙不是挖矿。崖上挥镐不叫翻沙。风暴后的打捞在工坊，不在沙滩。考勤逾期，崖和工坊一样锁。

周潮天灾

东八区每周一可能刮一次浅潮 / 灌仓潮 / 黑潮。只冲口袋里 3 万以上的超额，3 万及以下没事。这不是岸税。

工分票

岛上主要流通货币。买种、吃饭、工具、扩建都会用。榜看口袋现票，送出去会掉名次。

岸税

看口袋现票，未过 800 免征。东八区周一划入潮汐基金。本周新号免到下周。欠税不能买地 / 买棚 / 买园 / 升屋 / 买船 / 开坑 / 升镐。

岸维

看你开了多少产业，每天划，日单价 2 起。小屋 / 船按档 2 / 2 / 3。欠维修费同样不能扩产，开着的小馆暂停堂食。

潮汐基金

高于岛均可以捐，票数自填。低于岛均的人在东八区周二、周四、周六自动吃补贴，不用领、不用抢。每人顶 1000、不超过岛均。

你在岛上留下什么

等级 · 1～99

跟累计入账的工分票走，满级「潮汐本尊」。升级礼在档案里领。等级不单独占全服榜。

岛缘 · 无上限

你和这座岛发生过的一切。岸上动手只加，井下减，地板 0。全服榜的另一张是岛缘榜，不是等级榜。

档信

公共信用和印象。低了更容易出意外，档口票也可能打折。偷菜被抓会掉。

雾智

见闻、灶台、故事和特殊经历会改变。饱食 / 雾智 / 档信会慢衰减，没有硬死亡。

岛缘不是第二套等级

劳作、人情、通关故事会加；第一次下井 −25，之后每次进入再减。看一眼枯井不算。∞ 只表示无上限，不是第二个数字。

每日工分

档案里的工分是每天一轮的票，不是加入潮生会。潮生会不能入会。

BELOW THE WELL

潮下

中后期内容。岸上的礼貌、信用和规矩到了这里会换一种算法。可以输钱，可以负债，可以受伤，也可能被人把名字钉上墙。下井会减岛缘。
