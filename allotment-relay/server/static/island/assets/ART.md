# 手机地图插图位

把图放到同目录 `scenes/{id}.png`，页面会自动铺上，不用改代码。没有图时显示「插图位」框。

竖屏优先，透明底或铺满都可。建议 **1080×1920**。

| 文件 | 出现在哪 | 建议尺寸 |
|------|----------|----------|
| `scenes/island-map.png` | 岛屿总览（已就位；铺满一屏，底下不漏色） | 972×1619 |
| `scenes/home.png` | 家园院子 | 1080×1920 |
| `scenes/yards.png` | 份地页底图（已就位；海边草地，不是一块纯绿） | 941×1672 |
| `scenes/shore.png` | 海边 / 港口（已就位） | 1080×1920 |
| `scenes/plaza.png` | 潮汐广场（已就位） | 1080×1920 |
| `scenes/hut.png` | 岸畔小屋 | 1080×1920 |
| `scenes/bar.png` | 潮汐酒吧（已就位） | 1080×1920 |
| `scenes/theater.png` | 潮汐剧场（已就位） | 1080×1920 |
| `scenes/eatery.png` | 岸畔小馆（已就位） | 941×1672 |
| `scenes/hui.png` | 潮生会（已就位） | 941×1672 |
| `scenes/market.png` | 集市（已就位） | 941×1672 |
| `scenes/ting.png` | 听潮亭（已就位） | 941×1672 |
| `scenes/lianli.png` | 连理所（已就位） | 941×1672 |
| `plot.png` | 份地土地（已就位；和草地拼装，一页最多 9 块） | 512×512 |
| `grass.png` | 份地草地（已就位；空位垫草） | 512×512 |
| `chip-back.png` | 进地点后左上角「返回地图」（原图透明底，未另扣） | 2000×667 |
| `chip-bag.png` | 进地点后右上角背包迷你小组件；总览图上不显示 | 550×185 |
| `crops/{key}.png` | 作物图，按 catalog 英文 id | 256×256 |

参考原图可以放 `_src/`，运行时不读。
