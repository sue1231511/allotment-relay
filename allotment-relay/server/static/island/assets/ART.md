# 手机地图插图位

把图放到同目录 `scenes/{id}.png`，并同步生成同名 `.webp`；现代手机优先读取 WebP，PNG 只留给旧浏览器回退。没有图时显示「插图位」框。

竖屏优先，透明底或铺满都可。建议 **1080×1920**。
